# CODEC-AI
CODEC-AI is an AI-powered coding assistant built with React, Node.js, Express, MongoDB, and the Google Gemini API.
It allows users to submit code and get AI-generated feedback and assistance directly through the application.

## Features
* Submit code for AI analysis
* Debug code using Gemini
* Get explanations for code
* Get time and space complexity information
* Store coding history in MongoDB
* View previous coding submissions
* React frontend with Express backend

## API Endpoints

| Method | Endpoint   | Purpose                   |
| ------ | ---------- | ------------------------- |
| GET    | `/`        | Check backend status      |
| POST   | `/run`     | Submit code               |
| POST   | `/debug`   | Get AI debugging response |
| GET    | `/history` | Retrieve coding history   |

## Environment Variables
Create a `.env` file inside the backend directory:
MONGO_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_gemini_api_key
Do not upload your `.env` file to GitHub.

## Installation
Clone the repository:
git clone YOUR_REPOSITORY_URL
cd codec-ai

Install frontend dependencies:

cd frontend
npm install
npm run dev

Install backend dependencies:
cd backend
npm install
node server.js

## Gemini Integration
Gemini is used as the AI layer of CODEC-AI.
The backend sends the selected programming language and user's code to Gemini along with a prompt describing the required task. Gemini processes the request and returns the AI-generated response, which is then sent back to the React frontend.
For example, when debugging is requested:
User Code
   ↓
Express Backend
   ↓
Gemini API
   ↓
Bug Analysis
   ↓
React UI


## Database
MongoDB stores the coding history generated by the application.
Depending on the request, stored information can include:
* Programming language
* Code
* Output
* AI response
* Time complexity
* Space complexity
* Creation time
